# C.O.R.E — Central Organizer for Relaying Explanations

A free-to-build, multi-persona market-correlation prediction system for
the Indian stock market (NSE/BSE). Built and trained on Google Colab's
free tier using only free, open-source Python libraries.

## Status
Section 1 of 20 complete — see `docs/handoffs/` for full build history.

## Quickstart
1. Open `notebooks/01_environment_setup.ipynb` in Colab
2. Run all cells top to bottom
3. See `docs/handoffs/section_01.md` for what's built so far and what's next

## Personas
- **Arush** — bullish case
- **Cassandra** — bearish/risk case
- **Chitragupta** — pure statistical/backtested case
- **Hugo** — market psychology / sentiment case
- **C.O.R.E** — moderator, synthesizes into one verdict + confidence %

## Disclaimer
Educational/research project. Not financial advice. All predictions are
probabilistic outputs of a backtested statistical model, not guarantees.
